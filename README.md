## Scripts Overview

### 0_Check_System_driver_storage
Checks the available storage and driver/system information.

**Features:**
- Displays system storage details
- Checks disk usage
- Helps monitor storage capacity

---

### 1_Check_Specific_driver_freestorage
Checks free storage space for a specific drive.

**Features:**
- Monitors selected drive space
- Reports available storage
- Useful for storage alerts and maintenance

---

### 2_dynamicTodo_ListWhileAppend
A dynamic TODO list manager that allows appending tasks while the program runs.

**Features:**
- Add tasks dynamically
- Store and display task lists
- Simple command-line TODO manager

---

### 3_expenses_dictionary_json
Expense tracking system using dictionaries and JSON storage.

**Features:**
- Save expenses in JSON format
- Organize expense categories
- Read/write JSON data

---

### 4_inventory_modify_list
Inventory management script using Python lists.

**Features:**
- Add or modify inventory items
- Update stock information
- Simple inventory operations

---

### 5_inventory_CSV
Inventory management using CSV files.

**Features:**
- Read inventory data from CSV
- Update and save CSV records
- Lightweight inventory database

---

## Purpose

This collection is useful for practicing:

- Python file handling
- JSON and CSV operations
- List and dictionary manipulation
- Basic automation scripts
- Storage and inventory utilities
